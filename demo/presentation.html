Multi-LLM Router (LiteLLM)

Trocar de provider sem rebuild — whitelist garante seguranca

# app/llm/router.py
async def generate(self, provider, model, prompt) -> str:
    entry, chosen = self._resolve(provider, model)  # whitelist check
    return await litellm.acompletion(
        model=f"{LITELLM_PREFIX[entry.name]}/{chosen}",
        messages=[{"role": "user", "content": prompt}],
        api_key=entry.api_key, api_base=entry.base_url,
        temperature=0.7, max_tokens=1024, timeout=120,
    )

Knowledge Graph — Neo4j

Modelo de relacoes entre palavras e contextos

Modelo de Dados

(:WordNode)
  {text, language, frequency}

Relacoes:
  HAS_ROOT → raiz da palavra
  SYNONYM_OF → sinonimo
  USED_IN_CONTEXT → contexto de uso

Exemplo:
(running)—HAS_ROOT→(run)
(running)—SYNONYM_OF→(jogging)
(running)—USED_IN→(Sports)

Beneficios

Conexoes Semanticas
Palavras relacionadas por raiz, sinonimia e contexto
Aprendizado em Rede
Aluno aprende clusters de palavras, nao listas isoladas
Revisao Inteligente
Espacamento baseado em frequencia e relacoes no grafo
Spring Data Neo4j
